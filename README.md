# Rong Zhao — Academic Homepage

Personal academic website of Rong Zhao, Lecturer at North University of China.

## Website

The site is published with GitHub Pages:

- https://roy-sky.github.io/

## Project structure

```
.
├── index.html
├── favicon.svg
├── images/
│   ├── personal/
│   ├── education/
│   └── SIBA/
└── static/
    └── css/
        └── style.css
```

## Updating the website

- Edit `index.html` to update the biography, research interests, publications, experience, and contact information.
- Replace `images/personal/rong_zhao.jpg` to update the profile photo. Keep the same filename or update the image path in `index.html`.
- Add publication figures under `images/` and update the corresponding image and links in the Publications section.
- Update `static/css/style.css` to change the visual design.

The site uses plain HTML and CSS and does not require a build step or JavaScript framework.

## Deployment

GitHub Pages should publish the `main` branch from the repository root.
